# پی‌ریزی | آکادمی ساختن و مدیریت

یک وب‌اپ فارسی و راست‌به‌چپ برای پیوند ساختمان‌سازی با مدیریت بازرگانی و پروژه؛ با React، TypeScript، Vite و Recharts. این برنامه به بک‌اند، حساب کاربری یا کلید API نیاز ندارد.

## اجرا

پیش‌نیاز: Node.js نسخه ۲۰٫۱۹ یا بالاتر (در این محیط نسخه ۲۴ استفاده شده است).

```bash
npm ci
npm run dev
```

سرور توسعه روی پورت ۵۱۷۳ و رابط `0.0.0.0` اجرا می‌شود.

```bash
npm run build
npm run preview
```

خروجی پوشه `dist` را روی هر میزبان استاتیکی می‌توان منتشر کرد. مسیریابی مبتنی بر hash است و به تنظیم بازنویسی مسیرهای سرور نیاز ندارد.

## امکانات

- ۸ دوره و ۴۸ درس مستقل با مفهوم، مثال و تکلیف کاربردی
- ساختمان‌سازی، خاک و پی، سازه، تأسیسات و نازک‌کاری، مالی، برنامه‌ریزی، کارکنان، خرید و کسب‌وکار
- ۲۴ سؤال تستی، تصویری، محاسباتی و تشریحی؛ همراه با پاسخ توضیحی
- تمرین آزاد با فیلتر موضوع و نوع، و آزمون ترکیبی ۱۰ سؤالی
- سؤال‌های تشریحی با چک‌لیست **خودارزیابی**؛ بدون ادعای تصحیح خودکار متن
- ۶ محاسبه‌گر، از جمله تحقق برنامه هفتگی، با ورودی عدد فارسی و انگلیسی، فرمول و تفسیر نتیجه
- داشبورد، هدف ۷ روزه، نمودار روند، نقشه مهارت و تاریخچه پاسخ‌ها
- یادداشت درس، پاسخ تمرین، نشان ذخیره، جستجوی درس‌ها و فیلتر وضعیت پیشرفت دوره‌ها
- حالت تاریک و روشن، طراحی واکنش‌گرا و فونت محلی وزیرمتن
- پشتیبان JSON، بازیابی با تأیید جایگزینی و بازنشانی با تأیید صریح

## داده‌ها و محاسبه پیشرفت

اطلاعات در کلید `peyrizi-v1` در `localStorage` ذخیره می‌شود. داده بین مرورگرها، دستگاه‌ها و دامنه‌ها خودکار همگام نمی‌شود. برای انتقال، از صفحه تنظیمات خروجی بگیرید و در دستگاه مقصد بازیابی کنید. پاک‌کردن داده مرورگر یا تغییر دامنه می‌تواند دسترسی به سابقه را از بین ببرد.

نمودارها از عملکرد واقعی کاربر ساخته می‌شوند و داده نمایشی ساختگی ندارند. زمان آموزشی از مدت درس تکمیل‌شده به‌علاوه ۲ دقیقه برای هر پاسخ محاسبه می‌شود؛ زمان‌سنج حضور نیست. تکمیل دوباره یک درس، زمان اضافی ثبت نمی‌کند. هدف هفتگی تعداد درس‌های تکمیل‌شده در ۷ روز اخیر است.

محتوا در `src/domain/catalog.ts` قرار دارد. قیمت‌ها و موقعیت‌های عددی، مثال آموزشی‌اند. مطالب فنی برای شناخت و مدیریت پروژه نوشته شده‌اند و جای طراحی مهندسی یا ضوابط محل اجرای پروژه را نمی‌گیرند.

تصاویر اختصاصی با ابزار تولید تصویر ساخته شده و در `public/images` نگهداری می‌شوند. شماتیک‌های آموزشی SVG و نمودارهای مفهومی در خود برنامه هستند. برنامه در اجرا به سرویس تصاویر خارجی نیاز ندارد.

## ساختار پروژه

- `src/app` مسیریابی، پوسته برنامه و هماهنگی وضعیت یادگیری
- `src/pages` صفحه‌های برنامه
- `src/components` اجزای مشترک، کارت دوره و شماتیک‌های آموزشی
- `src/domain` مدل‌های TypeScript، محتوای آموزشی، ذخیره‌سازی، محاسبه‌گرها و شاخص‌های پیشرفت

## آزمون‌ها

```bash
npm run typecheck
npm run format:check
npm test
npm run test:e2e
```

تست‌های مرورگر با Chromium نصب‌شده در `/usr/bin/chromium` اجرا می‌شوند. در محیط دیگر، مسیر `executablePath` در `playwright.config.js` را با نصب Chromium آن محیط هماهنگ کنید. آزمون‌های مرورگر، ذخیره‌سازی و یادداشت‌ها، نمره‌دهی، آزمون ترکیبی، ۶ محاسبه‌گر، پشتیبان و بازیابی، حالت تاریک و نمایش موبایل را پوشش می‌دهند.
